# Изменения в v1.44.0

## v1.44.0

- **Регулярки для ключей/значений** (5.6) — добавлено правило `key_value_patterns` с `path`, `pattern` и `target` (keys/values): проверка соответствия ключей или значений регулярному выражению (напр. для K8s metadata.name, имён ключей). Пример конфига: `configs/k8s-name-patterns.yaml`.
