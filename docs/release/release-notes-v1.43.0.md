# Изменения в v1.43.0

## v1.43.0

- **Уникальность элементов списка** (5.5) — добавлено правило `unique_list_fields` с `path` и `field`: проверка, что элементы массива (по выбранному полю) не повторяются. Например, `spec.template.spec.containers[].name` — имена контейнеров должны быть уникальны. Пример конфига: `configs/k8s-unique-containers.yaml`.
