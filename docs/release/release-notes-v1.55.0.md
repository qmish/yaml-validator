# Изменения в v1.55.0

## v1.55.0 — Параллельная валидация (8.2)

### Добавлено

- **Флаг `--jobs N`** — параллельная валидация нескольких файлов. Число воркеров N ограничивает количество одновременно обрабатываемых файлов.
- По умолчанию `--jobs 1` (последовательная валидация, как раньше).

### Использование

```bash
# Валидация 10 файлов с 4 параллельными воркерами
yaml-validator validate file1.yaml file2.yaml ... file10.yaml --jobs 4

# Параллельность с 8 воркерами
yaml-validator validate **/*.yaml --jobs 8
```

Рекомендуется использовать `--jobs` равным числу CPU или меньше. Ускорение заметно на больших проектах с множеством YAML-файлов.
